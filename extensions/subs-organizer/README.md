# 구독 채널 정리함 (Chrome 확장 프로그램)

YouTube 구독 채널을 한눈에 보고 정리하거나, 여러 계정의 구독을 하나로 합치는 도구입니다.
AI나 외부 서버를 쓰지 않고, 모든 데이터는 이 브라우저 안에만 저장됩니다.

## 설치 (개발자 모드)

1. 이 폴더(`subs-organizer`)를 원하는 곳에 압축 해제합니다.
2. Chrome 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 고릅니다.
5. 툴바의 퍼즐 아이콘에서 **구독 채널 정리함**을 고정해 두면 편합니다.

## 사용법

1. 아이콘을 누르면 정리함이 열리고, 이 브라우저에 로그인된 YouTube 계정이 나열됩니다.
2. 계정을 1개 이상 고릅니다.
   - 1개: 그 계정의 구독을 정리합니다. 빼둔 채널은 실행할 때 구독 취소됩니다.
   - 2개 이상: 구독 목록을 합칩니다. 남길 계정을 고르면 그 계정에 새로 구독하고, 빼둔 채널은 구독 취소합니다.
3. 채널마다 최근 영상·쇼츠 업로드 시점과 활동 상태(활발 / 뜸함 / 휴면 / 영상 없음)가 표시됩니다.
   - 활발: 30일 안에 업로드, 뜸함: 1년 안에 업로드, 휴면: 1년 넘게 업로드 없음
4. 정리가 끝나면 **실행하기** → 확인 → **시작**.
   작업용 YouTube 창이 열리고 채널을 하나씩 처리합니다. 끝날 때까지 그 창을 닫거나 최소화하지 마세요.
5. 끝나면 남길 계정의 구독 목록을 다시 받아 목표와 비교하고, 남은 것만 다시 시도할 수 있습니다.

## 동작 방식

| 단계 | 쓰는 것 |
|---|---|
| 계정 목록 | YouTube 계정 전환 메뉴가 쓰는 데이터 (`/getAccountSwitcherEndpoint`) |
| 구독 목록 | 계정 번호별 구독 채널 페이지 데이터 (`/feed/channels?authuser=N`) |
| 최근 업로드 | YouTube 공개 RSS 피드 (`/feeds/videos.xml`) |
| 구독·구독 취소 | 채널 페이지(`?authuser=N`)의 구독 버튼. 누르기 전마다 남길 계정으로 열렸는지 확인 |

## 알려진 한계

- YouTube 웹 내부 구조를 읽는 방식이라, YouTube 화면이 바뀌면 동작하지 않을 수 있습니다.
- 브랜드 계정(하나의 Google 계정 아래 여러 채널)은 아직 지원하지 않습니다.
- 구독이 아주 많은 계정(수천 개)의 이어받기 요청은 실제 대량 계정으로 아직 검증하지 않았습니다.
- 너무 많은 채널을 한 번에 바꾸면 YouTube가 일시적으로 구독을 막을 수 있습니다. 채널마다 몇 초씩 간격을 둡니다.

## 파일

- `manifest.json` 확장 설정 (권한: storage, tabs, scripting / youtube.com 접근)
- `background.js` 아이콘 클릭, 실행 큐, 최종 대조
- `app.html` `app.css` `app.js` 정리함 화면
- `inject.js` YouTube 페이지 안에서 실행되는 함수 (계정·구독 목록 읽기, 버튼 확인·클릭)
- `common.js` 탭 이동·대기 도우미
