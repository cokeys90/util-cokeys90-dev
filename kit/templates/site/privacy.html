요약: 이 확장 프로그램에는 개발자 서버가 없습니다. 아래 정보는 모두 사용자의 브라우저 안에서만 처리·저장되며, 개발자나 제3자에게 전송, 판매, 공유하지 않습니다.

1. 처리하는 정보

정보용도저장 위치와 기간
브라우저에 로그인된 YouTube 계정의 이름, 이메일 주소, 프로필 사진, 핸들정리할 계정을 화면에 보여주고 고르게 하기 위해화면을 열 때마다 YouTube에서 다시 읽음. 실행을 시작하면 남길 계정의 이름, 이메일, 프로필 사진을 진행 화면 표시용으로 작업 정보에 저장하고, 데이터를 지우거나 다음 작업을 시작하면 지워짐
선택한 계정의 구독 채널 목록 (채널 ID, 이름, 핸들, 구독자 수, 프로필 이미지 주소)구독 목록 표시, 비교, 정리화면을 연 동안만 메모리에 보관. 실행 중에는 작업 목록에 채널 ID와 이름을 저장
채널별 최근 영상·쇼츠의 제목, 주소, 게시 시각 (공개 정보)채널 활동 상태 표시브라우저 저장소에 최대 12시간 보관 후 다시 확인
사용자가 빼둔 채널 목록, 남길 계정 선택, 실행 진행 상태정리 상태 유지, 중단된 작업 이어가기브라우저 저장소에 보관. 사용자가 지우거나 확장을 삭제할 때까지

이 확장 프로그램은 비밀번호, 쿠키, 인증 토큰 같은 로그인 정보를 읽거나 저장하지 않습니다. YouTube에 보내는 요청에는 브라우저가 평소처럼 사용자의 로그인 상태를 붙입니다.

2. 정보가 오가는 곳

  • www.youtube.com: 계정 목록과 구독 목록을 읽고, 사용자가 시작을 누른 경우에만 구독과 구독 취소를 실행합니다. 이는 사용자가 직접 YouTube를 쓰는 것과 같은 요청입니다.
  • YouTube 공개 RSS 피드 (www.youtube.com/feeds): 채널의 최근 업로드 시점을 확인합니다. 로그인 정보 없이 요청합니다.
  • 그 밖의 서버(개발자 서버, 분석 도구, 광고 서비스 등)와는 통신하지 않습니다.

3. 권한을 쓰는 이유

  • youtube.com 접근: 구독 목록을 읽고, 사용자가 요청한 구독·구독 취소를 실행하기 위해
  • scripting: 위 작업을 YouTube 페이지 안에서 실행하기 위해
  • storage: 정리 상태와 최근 업로드 확인 결과를 사용자 브라우저에 저장하기 위해

4. 저장된 정보 지우기

확장 프로그램의 첫 화면 아래 저장된 데이터 지우기를 누르면 이 브라우저에 저장된 정보가 모두 지워집니다. 확장 프로그램을 삭제해도 함께 지워집니다.

5. Chrome 웹 스토어 사용자 데이터 정책 준수

이 확장 프로그램이 처리하는 정보의 사용은 Limited Use 요건을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 따릅니다. 정보는 위에 적은 기능을 제공하는 데에만 쓰며, 광고, 신용 평가, 개인 프로필 생성에 쓰거나 다른 사람에게 판매·전달하지 않습니다. 사람이 정보를 열람하는 일도 없습니다.

6. 아동

이 확장 프로그램은 아동을 대상으로 하지 않으며, 아동의 정보를 따로 수집하지 않습니다.

7. 방침 변경

내용이 바뀌면 이 페이지에 시행일과 함께 알립니다. 정보 처리 방식이 크게 바뀌는 경우에는 확장 프로그램 업데이트 안내에도 함께 적습니다.

Privacy Policy

{{EXT_NAME}}, Chrome extension · Effective {{PRIVACY_UPDATED}}

Summary: This extension has no developer server. All information below is processed and stored only inside the user's browser. It is never transmitted, sold, or shared with the developer or any third party.

Information handled

  • Name, email address, profile photo, and handle of the YouTube accounts signed in to this browser: shown so the user can pick accounts. When a run starts, the target account's name, email, and photo are saved with the task so the progress screen can show them; they are removed when the user clears data or starts a new run.
  • Subscription lists of the selected accounts (channel ID, name, handle, subscriber count, image URL): used to display, compare, and organize subscriptions. Kept in memory; channel IDs and names are stored in the task queue while a run is in progress.
  • Public information about each channel's latest video and Short (title, URL, publish time): used to show channel activity. Cached in browser storage for up to 12 hours.
  • The user's selections and run progress: stored in browser storage until the user clears them or removes the extension.

The extension does not read or store passwords, cookies, or authentication tokens.

Network access

The extension communicates only with www.youtube.com, to read account and subscription lists, to subscribe or unsubscribe only after the user presses Start, and to read public channel RSS feeds. It does not contact any other server, analytics, or advertising service.

Deleting data

Use “저장된 데이터 지우기” (Clear stored data) on the extension's first screen, or remove the extension.

Chrome Web Store User Data Policy

The use of information received by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the features described above, is not used for advertising, credit-worthiness, or profiling, is not sold or transferred, and is not read by humans.
